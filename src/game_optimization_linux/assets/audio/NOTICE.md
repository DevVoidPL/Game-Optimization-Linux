# GameOpti Couch Mode audio provenance

All files in this directory are original procedural assets generated specifically for GameOpti by `scripts/generate-couch-audio.py`.

- Inputs: mathematical sine oscillators and deterministic numeric parameters only
- Third-party recordings or samples: none
- Recognizable melodies or console sounds: none
- Generator determinism: fixed formulas and no random input
- Effects: mono, 16-bit PCM, 22.05 kHz
- Menu music: 120-second stereo, 16-bit PCM, 44.1 kHz; a fixed 48-bar composition with harmonic progression, articulated bass, pad, pulse, sparse motif, and three arranged sections
- Files: `navigate.wav`, `confirm.wav`, `back.wav`, `open.wav`, `close.wav`, `adjust.wav`, `error.wav`, `launch.wav`, `menu-ambient.wav`
