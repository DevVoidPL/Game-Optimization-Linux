# Launcher artwork

`heroic.png` and `lutris.png` are launcher logos prepared for GameOpti. Preparation
trimmed the images, removed their flat backgrounds and downscaled them without
changing their colours. These finished assets are not regenerated by
`scripts/build-facet-icons.py`.

Steam uses the official colour icon in `../../brands/steam.png`; see
[upstream artwork attribution](../../brands/README.md).

Steam, Heroic Games Launcher and Lutris names and logos belong to their
respective owners and identify the launcher a game comes from.
