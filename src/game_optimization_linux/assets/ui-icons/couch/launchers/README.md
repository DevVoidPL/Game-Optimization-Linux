# Launcher logos (Couch Mode)

`steam.png`, `heroic.png` and `lutris.png` are prepared from files supplied by the
project owner in `GrafikiProgramu/` (`SteamLogo.png`, `HerocicLauncherLogo.png`,
`LutrisLogo.png`) by `gameopti-couch-icons/build_launcher_logos.py`. The script only
trims, removes the flat background and downscales; colours are not changed.

Steam, Heroic Games Launcher and Lutris names and logos belong to their
respective owners. They are used only to identify the launcher a game comes from.
