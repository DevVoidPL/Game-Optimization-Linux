# GameOpti roadmap

Updated: 14 November 2026.

## Current release

[GameOpti 2.3.0 Beta](docs/release-notes-2.3.0-beta.md) includes the AppImage
Wayland fix, simpler OptiScaler management, restored Couch controls, improved
Steam connection and game artwork. It remains a pre-release. The earlier
[2.2.0 Beta](https://github.com/DevLukaszNowak/Game-Optimization-Linux/releases/tag/v2.2.0-beta)
remains available. Built-in narration belongs to a separate application.

The Beta 2.0 feature set is already available: launcher profiles, Gamescope,
GameMode, MangoHud, OptiScaler and FSR variants, DLSS Enabler, post-processing,
frame generation, GPU-memory protection, Btrfs compression, performance
measurements, Proton tweaks and custom launch commands.

See the [README](README.md#features) for features and requirements, and the
[2.1 release notes](docs/release-notes-2.1.md) for the preceding release.

## Current work

- Collect beta feedback across more GPUs, distributions and game configurations.
- Prepare the native Arch/AUR recipe after approval of the GitHub release source.
- Fix reported bugs and improve Desktop and Couch layouts.
- Check graphics tools together across Steam, Heroic, Lutris and their Flatpak runtimes.
- Make installation, configuration, errors and restore actions easier to follow.

## Later plans

[GameOpti LXB](https://github.com/DevVoidPL/GameOpti-LXB) is a separate application
for controllers and TV use, with LineXinBar integration planned. Work on the
regular GameOpti application takes priority for now.

AI Graphics Remaster and broader game/engine recognition remain research
ideas without a release date. Existing resource-management tools have their
own kernel and driver requirements; they do not promise a performance gain.
